# Deskward — User stories

**Product:** [PRODUCT.md](./PRODUCT.md)


### Employee

- As an employee, I want one place to ask any work question and get an answer that is correct for my country and contract, so that I stop guessing or asking three colleagues.
- As an employee raising a grievance, I want my case handled confidentially by a person, never by a bot, and not visible to my manager, so that using the service is safe.
- As an employee requesting a workplace adjustment, I want a human route with a committed response time, so that my accommodation is not treated as a routine ticket.
- As an employee, I want to know when the thing I reported has actually been fixed rather than just closed, so that reporting friction feels worth doing.

### Line manager

- As a line manager, I want the answer to a people question in the flow of my work rather than a policy document to interpret, so that I stop routing decisions to HR that I could make myself.
- As a line manager, I want visibility of my team's open service cases excluding protected classes, so that I can support without intruding.
- As a line manager, I want the repeated administrative tasks my role generates surfaced as a friction item, so that my time is a considered cost rather than an assumed one.

### Tier-one service adviser

- As a service adviser, I want cases routed to me with jurisdiction, contract type and entitlement context already attached, so that I am not assembling facts before I can answer.
- As a service adviser, I want to flag an answer as wrong or out of date and see it taken out of service, so that I am not repeatedly correcting the same bad content.

### HR operations director

- As an HR operations director, I want true demand including informal requests to business partners, so that my capacity plan is built on reality.
- As an HR operations director, I want automated handling withdrawn automatically from any category whose reopen or escalation rate breaches threshold, so that deflection does not quietly damage service.
- As an HR operations director, I want the capacity shift from transactional to advisory tiers evidenced from case handling, so that the operating-model change is reported rather than claimed.
- As an HR operations director, I want each recurring friction item costed in employee hours and assigned to a named owner in IT or finance with the post-fix effect measured, so that the cost of organisational complexity is prioritised against their backlog rather than absorbed silently by mine.

### Governance administrator

- As a data protection officer, I want sensitivity classification to drive routing, visibility, retention and analytics eligibility as a system rule, so that protection does not depend on an adviser's judgement.
- As an HR compliance administrator, I want consultation obligations raised and recorded before a bot or routing change goes live in a jurisdiction that requires it, so that deployment is lawful.
- As an HR compliance administrator, I want contingent workers and their service scope identifiable in the case record, so that co-employment exposure is visible before it becomes a claim.
